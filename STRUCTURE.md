# Project Structure

- `apps/web-h5`: mobile consultation UI for web, WeCom, and Feishu.
- `apps/admin-web`: knowledge review, release, evaluation, audit, and operations UI.
- `backend`: FastAPI modular monolith, workers, providers, migrations, and tests.
- `packages`: generated API client, design tokens, and shared frontend tooling.
- `prompts`: versioned prompts and structured-output schemas.
- `evals`: approved datasets, rubrics, baselines, and generated reports.
- `tests`: cross-application end-to-end, load, security, and smoke tests.
- `infra`: container, gateway, observability, and deployment configuration.
- `docs`: architecture decisions, API, data governance, security, testing, and release records.
