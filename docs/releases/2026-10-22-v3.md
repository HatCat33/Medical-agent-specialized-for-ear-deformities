## 本次完成

### 患者端

- 文本、最多四张图片和按住说话输入，语音识别完成后自动发送。
- SSE 流式回答、停止生成、Markdown 安全渲染和中断内容保留。
- 回答随生成内容按完整句尽早播报，支持浏览器设备音色和兼容接口云端 TTS；云端后续片段预加载并保持原顺序。
- 顶部声音开关保存用户偏好；切换会话、静音或停止回答时取消当前和预加载音频。
- 手机历史会话采用 Push 推开交互，支持跟手拖动、快速轻扫、左滑关闭和点击轻遮罩返回。
- 手机顶部保留历史和新建会话入口，桌面只保留新建入口并使用侧栏自身的收起按钮。
- 空白会话去重并防止快速连续创建；推荐问题点击后直接发送。
- 移除患者端参考资料展示、回答头像、角色文字和流式光标；取消输入框自动聚焦。

### RAG 与管理端

- 医院 FAQ XLSX 校验、冲突阻断、版本化导入、增量合并、发布和回退。
- Chunk 完整内容查看、编辑、删除，以及缺失向量增量补全和草稿全量重建。
- 关键词与可选 Embedding 混合检索、动态阈值、低召回降级和生成上下文注入。
- RAG 来源关联保留给管理端评测和问答追踪日志，患者 Web 不展示参考资料。
- 单条检索实验与批量评测，支持从标准问题生成基础评测集，并计算命中率、Recall@K、MRR 和无结果准确率。
- 顶部导航管理端，集中提供运行总览、知识管理、检索评测、提示词管理、声音设置和任务记录。
- 文本、视觉、ASR、Embedding、设备 TTS 和云端 TTS 分层探活，展示供应商错误摘要、请求编号和排查建议。
- 系统/业务提示词草稿、发布与回退；声音参数、设备音色、云端音色 ID 和试听管理。

### 数据、运维与日志

- SQLite 与 Docker PostgreSQL 双数据库支持，使用 Alembic 迁移和 SQLite 数据复制校验脚本。
- 请求、媒体、模型和系统操作结构化日志，以及关联输入、输出、RAG 命中、提示词版本、耗时和错误的问答追踪日志。
- 数据库兼容升级脚本会在 SQLite 迁移前创建一致性备份。
- 环境模板覆盖聊天、视觉、ASR、TTS、Embedding、RAG、数据库、日志、跨域和管理员令牌配置。

## 当前限制

- PDF、视频转写内容尚未接入解析、审核、分块和检索流程。
- 飞书仍只保留模块边界；企业微信智能机器人 API 模式已在后续迭代接入 WebSocket 长连接、会话映射、消息去重、图片解密和流式回复，详见 [企业微信机器人接入](../operations/wecom-bot.md)。
- 尚无独立管理员账户、角色权限、多级审核审批和完整生产审计策略。
- 自定义或克隆音色需先在模型供应商侧创建，本系统当前保存并调用对应音色 ID。
- 当前后台任务适合单 API worker 演示；生产多实例需接入 Redis/Celery、对象存储、限流、告警和数据保留策略。
- 患者端 HEIC 转换模块和管理端基础组件包仍有超过 500 kB 的构建提示，后续应继续按路由与能力拆包；不影响本版运行。
- 医疗内容仍需医院审核；系统只能提供健康科普，不能替代医生面诊、诊断或治疗建议。

## 发布与回滚

第三版代码长期保留在 `medical_agent_26_10_22` 分支，并使用 `v26.10.22` 标签标记。回滚代码时必须同步核对目标版本的数据库迁移、`backend/.env` 配置和知识发布状态，不得直接用旧程序连接未经评估的新结构数据库。
