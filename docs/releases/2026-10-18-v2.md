# 第二版发布记录：2026-10-18

## 本次完成

- 多图加文字输入、预览、移除和发送。
- 手机系统图片选择器、多图上传和响应式单行输入区。
- 电脑端摄像头居中预览拍照弹窗，以及可收起并记忆状态的历史侧栏。
- 图片私有存储、附件历史、授权读取与随会话删除。
- 视觉模型独立配置和 OpenAI-compatible 多模态请求。
- 类豆包文字/语音模式切换，按住录音、松开转写并自动发送，以及历史回答播报。
- OpenAI-compatible 服务端 ASR 配置，录音默认不落盘。
- JSONL 结构化日志、请求 ID 和日志轮转。
- 媒体权限、格式校验、生命周期和多模态序列化测试。

## 验证结果

- 后端测试：13 项通过。

- Admin Web 与 H5 生产构建：通过。

- 真实模型：SenseVoice 转写成功；视觉模型全链路上传、流式回答和清理成功。
- 日志：请求、媒体绑定、模型结果和会话删除事件写入轮转 JSONL 文件。
