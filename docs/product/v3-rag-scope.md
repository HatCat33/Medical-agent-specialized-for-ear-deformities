# 第三版 RAG 产品范围

更新时间：2026-10-22

版本：`0.3.0`（阶段分支 `medical_agent_26_10_22`，标签 `v26.10.22`）

## 目标

将医院审核后的 FAQ 接入患者问答，同时保持知识检索、医疗安全和生成模型相互解耦。后续替换为自有微调模型时，不重新导入知识，也不修改会话和引用逻辑。

## 已实现

- 读取包含“分类、标准问题、答案内容”的 XLSX，原文件保持不变。
- 导入前统计空值、重复问题、异常有效日期和分类分布。
- 完全相同的重复答案合并；同一问题存在不同答案时默认阻止发布。
- 可显式排除冲突组并将行号写入发布质量报告。
- 知识发布版本和条目持久化，同一时间只使用最新发布版本。
- 无 Embedding 配置时使用中文二元词、问题相似度与答案关键词检索。
- 配置 OpenAI-compatible Embedding 后自动使用关键词与向量混合评分。
- 命中内容作为受控系统上下文传给模型，来源关联保留用于管理端评测和日志追踪；患者 Web 不展示参考资料。
- 低召回且 `RAG_REQUIRE_MATCH=true` 时停止通用模型补答。
- 管理端草稿、增量导入、chunk 查看/编辑/删除、向量后台任务、版本发布与回退、操作记录。
- 单条检索测试与标注评测集，计算命中率、Recall@K、MRR、无结果准确率，保存并导出报告。
- Docker PostgreSQL 配置、Alembic 结构迁移与原 SQLite 数据迁移脚本。

## 当前限制

- SQLite 与 PostgreSQL 均使用 JSON 向量和应用层排序；尚未启用 pgvector 原生索引。
- 尚未接入 Reranker，复杂长问题的排序效果需要评测后再决定模型。
- 管理端目前使用共享管理员令牌和单 API worker；多账户审批和独立任务队列尚未实现。
- PDF、视频转写、分段引用、知识失效日期自动控制尚未实现。
- XLSX 的“有效日期”存在异常文本，当前只保留质量告警，不参与过滤。

## 验收要求

- 使用脱敏问题集分别评估 Recall@K、引用准确率、无答案拒答率和医学事实一致性。
- 冲突 FAQ 完成医院审核前不得进入发布版本。
- 自有微调模型必须通过 OpenAI-compatible 流式接口接入，并重新执行安全与 RAG 评测。
