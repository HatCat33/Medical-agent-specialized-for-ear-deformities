# 第一版产品范围

更新时间：2026-10-16

## 目标

第一版用于验证患者端问答、医疗安全边界和历史会话是否能完整运行。先验证产品流程，医院 FAQ 在完成内容审核和数据清洗后再进入 RAG 知识库。

## 已确认条件

- 部署：前期租用云服务器与按需云算力。
- 入口：必须支持公网移动端 H5，后续可嵌入飞书或其他应用。
- 用户：医院患者及家属。
- 内容：医院已有整理资料，医生相关素材已取得授权。
- 人工转介：第一版不实现，保留服务和数据模型扩展位。
- 并发、预算、数据保留期、运维和更细的合规方案：在试用数据明确后定稿，均通过配置或部署策略调整。

## 第一版包含

- 文本问答页面。
- 新建、查看和删除历史会话。
- 匿名访客隔离。
- SQLite 本地持久化。
- OpenAI-compatible 模型接口。
- 无模型密钥时可运行的 demo 模式。
- 急症提示，以及诊断、分型、手术判定和处方请求的基础边界控制。

## 第一版暂不包含

- FAQ/PDF/视频知识的 RAG 检索和引用。
- 图片、语音和视频输入。
- 飞书、企业微信事件回调和身份映射。
- 人工转介流程。
- 医院后台的内容审核与知识发布界面。

## 后续演进顺序

1. 清洗、医学审核并发布 FAQ，加入可追溯引用的 RAG。
2. 建立 PDF 和视频转写的统一采集、切分、审核与版本发布管线。
3. 增加图片与文字联合输入；模型输出仍定位为健康科普和就医沟通辅助。
4. 接入飞书渠道适配器，共用会话、安全、知识检索和模型编排服务。
5. 根据试用量确定 PostgreSQL、对象存储、队列、可观测性、保留期及云上部署规格。
