# 第三版回复风格候选提示词

这里保存患者问答的业务提示词候选，不会被程序自动加载。请在管理端“提示词管理”中基于当前版本创建草稿，将候选内容复制到“业务提示词”，保存并发布后才会影响新问答。

“系统提示词”应继续保留管理端显示的当前医疗安全基线，不要用本目录内容替换。确定性的诊断、处方、图片判定等拦截仍由后端安全模块执行。

建议先试用 `01-professional-warm.md`，再使用固定脱敏问题集比较准确性、自然度、追问质量、拒答边界、引用忠实度和回答长度。一次只发布一个版本，并记录版本名称和评测结果。

| 编号 | 风格 | 适用方向 |
|---|---|---|
| 01 | 专业温和 | 默认综合基线 |
| 02 | 简洁直接 | 高频简单问题、移动端快速阅读 |
| 03 | 结构化科普 | 复杂概念和流程说明 |
| 04 | 先澄清再回答 | 信息不足、歧义问题 |
| 05 | 家长沟通 | 儿童患者家属场景 |
| 06 | 就诊准备 | 检查、就诊、护理准备 |
| 07 | 图文咨询 | 图片加文字输入 |
| 08 | 自然口语 | 更接近真人医生交流感 |
| 09 | 知识库严谨 | 医院 FAQ 忠实回答与低幻觉 |
| 10 | 综合增强 | 多轮、RAG、拟人和安全的综合候选 |

在没有经过授权且完成清洗的医生语料、表达偏好和医院审核前，不应宣称已“复刻某位医生”。当前候选只定义一般医生式沟通风格；后续应从授权素材提炼明确的风格规则，而不是把视频转写全文直接塞进系统提示词。
